# Proverse docs

Documentation for the Proverse V1 build. Start with whichever fits what you're doing:

| Doc | Read this when... |
| --- | --- |
| [product-overview.md](./product-overview.md) | You need the product thesis, principles, user journeys, or V1 scope — what this app is and why it works the way it does. |
| [architecture.md](./architecture.md) | You're adding a feature and need the stack, layering, and where things live. |
| [data-model.md](./data-model.md) | You're touching the database — entity groups and the invariants the schema alone can't enforce. |
| [design-system.md](./design-system.md) | You're building UI — tokens, typography, and the component inventory. |
| [dev-setup.md](./dev-setup.md) | You're setting up the project locally. |
| [testing.md](./testing.md) | You're writing or running tests. |
| [deployment.md](./deployment.md) | You're deploying to production. |
| [platform-api.md](./platform-api.md) | You're building against or extending the versioned `/api/v1/*` surface or API keys. |
| [localization.md](./localization.md) | You're touching enum-backed display labels or planning further i18n work. |
| [decisions.md](./decisions.md) | You want to know why something was built a particular way, or what's still open. |

The root [`README.md`](../README.md) has the condensed quickstart; this directory has the depth.
[`roadmap/`](./roadmap/README.md) holds the longer-term product direction beyond V1,
decomposed into independent workstreams each sized for its own Claude Code session.
